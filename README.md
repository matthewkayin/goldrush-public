# Gold Rush - Public Repo

This is the public-facing repo of my game Gold Rush. This repo contains all of the code for the game, but it does not contain any of the games assets. This repo is meant as a portfolio piece demonstrating my technical skills and what I have accomplished in making this game.

## What is Gold Rush?

Gold Rush is a Wild West real-time strategy game developed in C++ and OpenGL. As of the time of writing, the game is feature-complete and is planned to be released on Steam for Windows, Mac, and Linux in Fall of 2026. [Steam Page](https://store.steampowered.com/app/3774270/Gold_Rush/)

## Who made it?

I (Matthew Madden) did all of the programming on the project. 

I did not use any generative AI to write the code seen here, however I did sometimes use LLMs as a super-google in order to figure out how to implement certain features (for example, I needed to figure out how to get my host program to print a Lua stacktrace whenever a Lua error was encountered, and I used LLMs to figure out how to do that).

Additionally, I made all of the art assets for the game. For sound effects, I sourced most of the sounds off of freesound.org, sometimes making edits or combining multiple sounds to get the exact sound I wanted.

The music for the game was composed by [Tommy Norris](https://www.tommynorrismusic.com/).
